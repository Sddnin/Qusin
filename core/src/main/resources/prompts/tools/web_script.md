Run a JavaScript program against the current web page to do repetitive multi-step work in one call: read many list items, page through results, fill several fields. Not for a single action: use web_tap/web_type_text for that. code is the body of an async function; return a JSON-serialisable value. The script has no DOM: document, window, location, fetch and every other browser global are undefined; only plain JavaScript (Math, JSON, Array, …) and `qusin` are there, and everything qusin returns is plain data (always await): qusin.snapshot() → {snapshotId, elements:[{ref, role, name, center}]}; qusin.read({maxChars, offset}) → page text chunk {text, nextOffset}; qusin.queryAll(cssSelector, {fields: ['text','attrs','value','box'], limit, maxChars}) → {items:[{tag, text, attrs, value, box}], total}; qusin.query(cssSelector, opts) → first item or null (fields ['count'] → number); qusin.text(cssSelector) → visible text (password-like values read as ***); qusin.tap(ref); qusin.type(ref, text, {enter}); qusin.scroll('down'|'up'|'left'|'right', {amount}); qusin.navigate(url); qusin.wait(ms) or qusin.wait({text, timeoutMs}) → true/false; qusin.log(...). tap/type use refs from the latest qusin.snapshot() in the script. Every action runs through the same execution and recording path as a normal call, including send, post, order, delete and pay. A failed qusin call throws an Error whose message starts with the error code. Limits: {{max_actions}} actions, {{max_reads}} reads, {{max_seconds}} s. A navigation that loads a new page ends the script (endedBy=navigation). Returns result (JSON), logs, and actions with each outcome. Call web_observe before acting after it: the page may have changed.
