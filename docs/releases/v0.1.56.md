# Qusin 0.1.56 · Ultra Sandbox & MCP

## MCP workspace

- Add a curated catalog of 74 MCP presets across code hosting, documentation, design, databases, observability, productivity, payments, and media.
- Add guided connect, OAuth authorization, API-key fields, custom server setup, connection health, enable/disable, edit, and remove flows.
- GitHub and Notion use their hosted remote MCP endpoints and OAuth; Canva uses the official remote MCP endpoint and a pre-registered OAuth client.
- Store API keys, OAuth tokens, and declared secret fields in the encrypted MCP secret store. Secret fields are excluded from plain server configuration.
- Connect enabled MCP servers at the start of a top-level task, expose their discovered tools to the agent tool dispatcher, and close sessions with the task resource scope.
- Persist oversized MCP tool results inside the conversation workspace and return a reference for the agent to read, rather than expanding the chat context with the entire payload.
- Preserve restricted trust by default and the existing high-impact action approval path.

## Sandbox

- Add a dedicated `/opt/qusin/mcp-cache` mount, separate from `/workspace` and `/opt/qusin/skills` and excluded from normal workspace file/share path APIs.
- Install catalog-declared npm/PyPI stdio servers only after explicit package consent, with exact package versions and source labels.
- Disable npm install scripts, require binary-only PyPI packages, clean failed installs, and mark successful cache entries only after installation completes.
- Pass stdio server credentials through validated environment variables, never command-line arguments; keep the existing two-argument stdio launcher API compatible.

## Canva setup

Canva is listed and configured in the catalog, but it is not pre-authorized. Create an app in Canva Developer Portal, enable Canva MCP, generate a client secret, and add this exact redirect URL under Outside Canva → Redirect URLs:

`http://127.0.0.1:43827/auth/callback`

Enter the app's Client ID and Client secret in Qusin, then authorize the Canva account. Every Canva user signs in individually. Some Canva capabilities depend on the account plan and permissions.

## Integration notes

The catalog contains connection presets, not pre-connected accounts. Each provider still controls availability, OAuth support, account permissions, rate limits, and required credentials. A connection is usable only after its setup/authentication succeeds and Qusin discovers its tools. Not every catalog entry has been live-tested against the provider from this environment.
