# Qusin 0.1.53

<!-- qusin-lang: en -->

## What's new
- Personal conversations now have separate histories, a conversation picker, and a new-conversation action. Existing single-thread history is migrated and retained.
- Personal replies can stream while the model is responding when the selected provider supports streaming.
- Added a shared **Create files** setting for Personal and Work. Turning it off removes dedicated file-write/export tools and blocks Personal delegation requests whose goal is to create or export files.
- Refined the Personal/Work switcher with a clearer selected state and a more rounded segmented control.
- Bundled the expanded file-creation skills and their supporting scripts and references.

## Fixes
- Fixed Android compilation in the Personal conversation list by using a statement conditional for the optional live-reply and pending rows.
- Updated skill-index snapshots and generated README skill lists for the expanded bundled catalog.
- Corrected bundled-script references, license headers, and archive-script coverage tests.
- Corrected the disabled file-creation regression test to inspect the actual tool result.

## Tính năng mới
- Cá nhân hỗ trợ nhiều hội thoại độc lập, lịch sử riêng, chọn hội thoại và tạo hội thoại mới. Lịch sử một luồng cũ được chuyển đổi và giữ nguyên.
- Hiển thị phản hồi trực tiếp trong lúc model xử lý nếu nhà cung cấp model hỗ trợ streaming.
- Thêm cài đặt **Tạo file** dùng chung cho Cá nhân và Công việc. Khi tắt, các công cụ ghi/xuất file chuyên dụng bị ẩn và Personal chặn việc giao task có mục tiêu tạo hoặc xuất file.
- Làm rõ trạng thái tab đang chọn trong thanh chuyển Cá nhân/Công việc và bo tròn giao diện.
- Bổ sung bộ kỹ năng tạo file cùng script và tài liệu hướng dẫn đi kèm.

## Sửa lỗi
- Sửa lỗi biên dịch Android trong danh sách hội thoại Cá nhân khi hiển thị phản hồi trực tiếp hoặc trạng thái đang chờ.
- Cập nhật snapshot chỉ mục kỹ năng và danh sách kỹ năng được tạo tự động trong README.
- Sửa tham chiếu script, giấy phép script và bổ sung kiểm thử chạy thật script tạo tệp nén.
- Sửa kiểm thử hồi quy cho thiết lập tắt tính năng tạo file để kiểm tra đúng kết quả công cụ.
